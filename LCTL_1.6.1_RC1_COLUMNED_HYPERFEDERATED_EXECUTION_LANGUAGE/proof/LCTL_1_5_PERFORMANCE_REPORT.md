# LCTL 1.5 Performance Report

The package includes a host-local worker characterization over 1, 2, 4 and 8 workers for the parallel Bell task DAG. Results are stored in `LCTL_1_5_PERFORMANCE_MATRIX.json`. Because the benchmark is small and JVM startup dominates external wall time, this report does not extrapolate cluster scalability or claim speedup beyond measured host behavior.
