# LCTL 1.4 Physical Target Blocker

Physical parallel and distributed QPU execution remain `BLOCKED_EXTERNAL_AUTHORITY`.

The package contains no authenticated physical multi-QPU endpoints, signed/live calibration authority, qualified inter-QPU quantum link, physical execution receipts, or measurement receipts. The reference logical-quantum router and protocol emulator are therefore not represented as hardware execution.

The default reference profile remains offline/fail-closed. A future physical qualification must supply authenticated target evidence through a separately enabled adapter and preserve source/lowering/plan/receipt provenance.
