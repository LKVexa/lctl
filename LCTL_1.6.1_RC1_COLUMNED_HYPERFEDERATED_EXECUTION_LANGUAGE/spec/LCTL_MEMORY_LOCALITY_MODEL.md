# LCTL Memory and Locality Model

Classical hierarchy classes: register, local, cache, NUMA, device, host, remote, persistent.

Quantum locality classes: logical qubit, physical qubit, QPU partition, inter-QPU link.

The reference metadata can express capacity and placement; capacity overruns fail closed. Distributed resource reports expose bytes moved, messages, remote-gate count, ebit use, quantum links, and related logical costs. Detailed machine-calibrated cache/NUMA penalties remain target-specific.
