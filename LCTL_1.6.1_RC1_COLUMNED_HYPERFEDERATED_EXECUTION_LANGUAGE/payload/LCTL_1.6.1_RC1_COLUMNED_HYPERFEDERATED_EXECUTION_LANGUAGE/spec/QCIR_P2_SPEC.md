# QCIR-P2/1.0

QCIR-P2 is the deterministic execution-plan IR for LCTL 1.3.

Reference fields:
- source language/profile;
- source SHA-256;
- SES;
- partition plan;
- placement;
- classical and quantum routes;
- temporal schedule;
- execution class and physical-boundary flags;
- plan SHA-256.

Future schema revisions will add explicit ebit lifecycle, recovery policy, calibration epoch, error-ledger links, and event-replay authority as structured records rather than embedded companion ledgers.
