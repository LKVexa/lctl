# Learned System → LCTL Migration

## Preserved
- ledger-shaped deterministic source;
- bundle/frame/tuple architecture;
- explicit regime, assumptions, error, confidence, proof;
- Q1-Q6 admission discipline;
- local-only / backendless policy;
- source/frame integrity seals;
- 1,205-record semantic memory as non-executable learned evidence.

## Replaced or specialized
The classical `MSSLB-LX → MCRT-K → MSSL-S → BWX1` execution path is not renamed. LCTL defines its own `LCTL Bundle → QFRAME → QTUPLE → QCIR → simulator/adapter` path and a quantum-specific type, ownership, measurement, channel, resource, and proof model.

## Admission rule
A record learned under the prior system is not automatically a LCTL rewrite. It must prove a LCTL semantic image, quantum/classical regime, validity assumptions, derivation, lowering/retraction/replay, and final Q6 disposition.
