# LCTL 1.4 Error Algebra Report

The 1.4 error layer keeps probability, variance, and unresolved/other terms separate and refuses hidden scalarization. It requires independence before variance addition and includes a conservative unresolved path for covariance/correlation cases.

This is an implemented reference algebra, not a complete calibrated distributed quantum-error model. Covariance matrices, physical calibration uncertainty, and full error-aware Pareto scheduling remain future gates.
