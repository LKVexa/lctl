# Local Reference Runtime

Commands:

`java -jar msslb-lx-runtime.jar verify bundle.mssllx`  
`java -jar msslb-lx-runtime.jar inspect bundle.mssllx`  
`java -jar msslb-lx-runtime.jar run bundle.mssllx`  
`java -jar msslb-lx-runtime.jar compile-bwx bundle.mssllx out.bwx`  
`java -jar msslb-lx-runtime.jar knowledge "backpropagation jacobian"`  
`java -jar msslb-lx-runtime.jar learned-summary`

The knowledge command queries the embedded local compendium semantic memory. It does
not call a server or network.
