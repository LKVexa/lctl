# Q1-Q6 Learning Gate

The compendium repeatedly uses a six-stage proof pattern. MSSL-S turns it into the
admission protocol for new learned semantics.

## Q1 — Class

What mathematical class is the claim? What is its differential/execution signature?

## Q2 — Image

What representation or semantic image does the language assign to it?

## Q3 — Regularity

What assumptions make that representation valid?

## Q4 — Derivation

How is the claim obtained?

## Q5 — Retraction / Replay

How does it reduce, replay, compile, retract, or deliberately refuse reduction to a
lower layer?

## Q6 — Admission

Should the claim enter authoritative local semantic memory?

## Fail-closed rule

If a frame contains `LEARN` but lacks any one Q1-Q6 pass record, or the frame does
not say `ADMIT=admit`, verification fails.

A Q1-Q6 pass proves only the declared semantic claim under its assumptions. It does
not create external evidence or operational maturity.
