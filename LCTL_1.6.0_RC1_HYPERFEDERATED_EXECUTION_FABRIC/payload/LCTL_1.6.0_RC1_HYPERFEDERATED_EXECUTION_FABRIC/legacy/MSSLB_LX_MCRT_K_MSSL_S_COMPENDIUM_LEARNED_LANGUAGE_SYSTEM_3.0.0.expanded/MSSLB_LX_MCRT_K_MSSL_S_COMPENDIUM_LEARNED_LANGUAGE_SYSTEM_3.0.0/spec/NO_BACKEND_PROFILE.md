# Backendless Learned Profile

Learning does not introduce a backend.

The semantic memory is a local read-only resource packaged beside/inside the
reference runtime. Candidate LEARN rows are stored in the source bundle itself.

The canonical profile opens no sockets and requires no server, daemon, database,
vector database, model endpoint, RPC layer, cloud runtime or remote registry.

Distributed-computing concepts may be represented as MODEL/KNOW semantics while
NETWORK remains `deny`.
