# Semantic Regimes

The runtime validates regime labels because the compendium repeatedly shows that
exactness status is part of the result.

`exact` — exact but not necessarily linear.  
`exact_linear` — exact in the stated linear/operator representation.  
`linearized` — valid under a declared local/tangent/small-parameter approximation.  
`approximate` — approximation with explicit error contract.  
`stochastic` — probabilistic execution/model semantics.  
`structural_analogue` — correspondence preserves selected structure, not identity.  
`nonlinear` — explicitly nonlinear.  
`combinatorial` — combinatorial/discrete structure is load-bearing.  
`no_faithful_form` — the attempted reduction is rejected.  
`impossibility` — impossibility/undecidability/consensus-style boundary.  
`mixed` — intentionally mixed regime.

`no_faithful_form`, `impossibility`, and `structural_analogue` are valid learned
results, not errors.
