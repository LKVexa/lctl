# 2.0 -> 3.0 Migration

| 2.0 | 3.0 |
|---|---|
| MSSLB-FX | MSSLB-LX |
| MCRT-F | MCRT-K |
| MSSL-T | MSSL-S |
| FACE/KIND + opcode | FACE + opcode + epistemic type columns |
| proof tag only | assumptions + error + confidence + proof |
| LEARN string/state | auditable LEARN relation + Q1-Q6 gate |
| static provenance | local semantic memory + field profile |
| exact machine semantics | exact machine plane + explicit learned/model plane |

The 24 BWX1 CODE operations remain compatible.
