# Lesson 26: Structural Analogue

## Goal

Do not confuse analogy with exact identity.

## Rule

A learned language is not one that accumulates more opaque strings. It is one that
records **what kind of claim is being made, under which assumptions, with what error,
confidence and proof path, and whether the claim can be lowered faithfully**.
