# Column Dictionary

`ROW` stable identity; `FACE` DECL/CODE/MODEL/ASSERT/EVIDENCE/LEARN/RESOURCE/TRANSFORM; `LANE` scheduling/semantic lane; `QSPACE` Hilbert/subsystem domain; `OP` operation; `OUT` destination; `CTRL` explicit control; `A`,`B` operands; `PARAM` typed parameter; `TYPE` semantic type; `BASIS` basis; `REGIME` exactness/approximation regime; `ASSUME` validity assumptions; `ERROR` explicit envelope; `RESOURCE` cost annotation; `CONF` confidence [0,1]; `PROOF` evidence identifier.
